# Malleable C2

1. [ ] Open a new PowerShell window in Terminal.
1. [ ] SSH into the team server VM.
  1. ```ssh attacker@10.0.0.5```
  2. The password is ```Passw0rd!```.

1. [ ] Move into the profiles directory.
  1. ```cd /opt/cobaltstrike/profiles```

1. [ ] Open *default.profile* in a text editor (e.g. vim or nano).
1. [ ] Add the following stage block:

    ```Profile-nocolor
    stage {
    ```

