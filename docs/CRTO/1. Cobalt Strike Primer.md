# Create Listeners

1. [ ] Go to **Cobalt Strike > Listeners** (or click the headphones icon) to bring  up the listeners tab.

!IMAGE[headphones.png](instructions347649/headphones.png)

2. [ ] Click the **Add** button at the bottom of the tab to create a new listener.

!IMAGE[listener-tab.png](instructions347649/listener-tab.png)

3. [ ] Create the following listeners:

### HTTP

1. Name: ```http```
2. Payload: **Beacon HTTP**
3. HTTP Hosts: ```www.bleepincomputer.com```
4. HTTP Host (Stager) : ```www.bleepincomputer.com```

## SMB

1. Name: ```smb```
2. Payload: **Beacon SMB**
3. Pipename: ```TSVCPIPE-4b2f70b3-ceba-42a5-a4b5-704e1c41337```

## TCP

1. Name: ```tcp```
2. Payload: **Beacon TCP**
3. Port: ```4444```
4. Bind to localhost: **False**

## TCP (local)

1. Name: ```tcp-local```
2. Payload: **Beacon TCP**
3. Port: ```1337```
4. Bind to localhost: **True**

# Generate Payloads

1. [ ] Generate payloads for each listener.
  2. Go to **Payloads > Windows Stageless Generate All Payloads**
  3. Folder: ```C:\Payloads```
  4. Click **Generate**

!IMAGE[generate-all-payloads.png](instructions347649/generate-all-payloads.png)

# Interact with Beacon

1. [ ] Run *C:\Payloads\http_x64.exe* and a new Beacon session should appear.
